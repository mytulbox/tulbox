# TULBOX

Static site. No build step.

## Weekly update (Monday)
1. Open `content/week.js`. Change `WEEK_LABEL` and the `WEEK` list.
2. Check-offs reset automatically when `WEEK_LABEL` changes.
3. Optional: add a post at the top of the list in `content/posts.js`.
4. Commit and push. The site redeploys on its own.

## Files
- `index.html`  page structure
- `style.css`   colors and layout (colors are the variables at the top)
- `app.js`      workout board and signup behavior
- `content/`    the only files you edit weekly

## Preview locally
Open `index.html` in a browser.
